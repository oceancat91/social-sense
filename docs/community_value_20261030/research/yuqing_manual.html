总览

一、总览介绍与设置

  1. 什么是总览

    总览页从多个维度, 用可视化的方式展示自身账号的监测和使用情况。包括预警信息、敏感信息、信息属性走势图、信息来源占比、监测详情、热门方案和账号详情等维度24小时内方案数据，30分钟更新一次统计结果。

  2. 如何设置总览

    点击总览页右侧的设置按钮，跳出弹框，选择需要监测的方案，点击保存后，即可支持查看不超过10个方案的整体概况。

  3. 如何切换维度

    鼠标悬浮至模块右上角，点击修改，跳出弹框，选择需要展示的维度；可自定义维度名称；预警信息、热门信息、敏感信息、实时微博可自定义方案。

  4. 如何查看更多

    鼠标悬浮至模块右上角，点击放大，跳出弹框，可滑动查看更多信息。

舆情监测

一、什么是舆情监测

  1. 舆情监测是系统基于用户添加的地域、事件等关键词，对通过对新闻、微博、微信、互动论坛、客户端、视频等全网8类信息源进行海量信息检索，向用户展示关键词相关的全网信息及其分析图表，实现用户的网络舆情监测和新闻专题追踪等信息需求

  2. 亿级数据实时更新，监测方案支持无限制次数修改，修改/创建方案后即刻生效，且支持回溯18个月历史数据

二、监测方案

2.1 配置方案

如未设置过方案，进入舆情监测后，将引导设置方案。

快速配置

  1. 精准地域：输入并选择您需要的监测方案所在地区，最多支持10个地名，系统将通过您输入的地域进行研判，去除跟该地域无关的信息。关闭精准开关后，该地域词不生效。

  2. 地域关键词：输入地域相关词语，关键词以空格隔开；或通过词库勾选，最小可选择的行政单位到区县一级【默认显示单位所在地的地域关键词】。

  3. 主体关键词：输入主题相关词语，关键词以空格隔开；或通过词库勾选，词库分为了16大类，支持搜索标签。

  4. 事件关键词：输入主题相关词语，关键词以空格隔开；或通过词库勾选，词库包含但不限于政法负面词、市场管理、司法问题等14大类常见事件，支持搜索标签。

  5. 排除关键词：输入需排除的词语，排除词以空格隔开；或通过词库勾选，词库包含广告、黄色等三类垃圾信息排除词，当信息命中排除词语，将不展示该信息。

  6. 逻辑关系：各关键词组中的关键词之间为或的关系，词组之间为且的关系。


高级配置

  1. 精准地域：输入并选择您需要的监测方案所在地区，最多支持10个地名，系统将通过您输入的地域进行研判，去除跟该地域无关的信息。关闭精准开关后，该地域词不生效。

  2. 监测关键词：输入需要监测的关键词，词语之间以关系符“+”、“|”、“(”、“)”组合，+表示“与”的关系，如A+B，同时监测到A和B才会显示舆情信息；|表示“或”的关系，如A|B,只要监测到A或者B中的1个就会显示舆情信息；（）表示一个整体关系，如(A+B)|C，只要监测到A+B或者C就会显示舆情信息。

  3. 排除关键词：输入需排除的词语，排除词以空格隔开；或通过词库勾选，词库包含广告、黄色等三类垃圾信息排除词，当信息命中排除词语，将不展示该信息。

  4. 逻辑关系：各关键词组中的关键词之间为或的关系，词组之间为且的关系


修改方案

  1. 选择需要修改的方案，点击右上角修改方案，即可对方案名称、方案关键词、精准地域、精准字距、监测行业进行修改。

  2. 引用方案：创建/修改方案时，可通过引用方案快速配置已有方案关键词。


2.2 方案管理

  1. 新建方案组：点击监测方案处“+”或方案组设置菜单，选择创建方案组，选择所属文件夹【如不选则新建文件夹为一级文件夹】，输入文件夹名称保存即可

  2. 新建方案：点击监测方案处“+”或方案组设置菜单

  3. 其他操作：支持对方案进行移动、删除、修改等操作

三、信息列表

3.1 筛选信息

支持对监测时间、信息属性、匹配方式、信源区域、来源类型、微博信息类型等21个条件筛选信息；保存条件后，再次查看该方案将以此为默认条件。

  1. 监测时间：支持近18个月的数据回溯，选择需要查询时间范围进行查看

  2. 信息排序：支持智能排序、时间升序、时间降序、采集降序、相似文章数降五种排序方式

  3. 信息属性：支持对系统算法研判得出的敏感、中性、非敏感三类信息属性，进行筛选或全选查看【支持多选】

  4. 匹配方式：支持对关键词命中位置进行筛选，可对标题、正文进行单选或全选查看

  5. 结果呈现：支持对系统模型判断得出的正常信息、噪音信息进行单选或全选查看

  6. 相似文章：选择合并，则会将系统判定的相似信息合并呈现；不合并，则呈现所有信息

  7. 精准筛选：打开精准筛选按钮后，精准设置内的词距、地域、排除行业条件对所有结果生效。

  8. 媒体类型：对所有信源按照系统规则划分为央级媒体、省级媒体、地市媒体、重点媒体、中小媒体五大类型，支持多选或全选查看

  9. 信源区域：根据信息来源网站的备案地址或者发布微博时的ip地址筛选信息来源，支持省内【账号所在省】、省外、全部或其他单个省份进行筛选查看

  10. 信息浏览：支持对已读、未读信息单选或全选查看

  11. 定向监测：支持人民网留言板、今日头条、抖音、贴吧、自定义设置的定向监测网站/账号进行筛选查看

  12. 信息类型：支持对内容、评论数据进行单选或全选查看

  13. 更多筛选：包括但不限于微博认证、微博内容、微博类型、涉及方式等微博数据筛选条件及图文识别、识图模式等其他选项

  14. 来源类型：对全部信息来源按照新规则划分为网站、微博、微信、客户端、互动论坛、视频、数字报、评价八大来源类型，支持单选、复选、多选查看，并可对以上类型的二级/三级分类进行筛选


3.2 信息操作

  1. 收藏信息：点击收藏按钮，可对信息进行分组收藏【支持批量操作、添加新收藏夹】

  2. 加入素材：点击添加素材按钮，可对信息进行分组添加至简报素材库【支持批量操作、添加新素材库】

  3. 信息下发：点击下发按钮，支持对信息通过微信群/钉钉分享、邮件报送、微信报送、短信报送、QQ报送、APP报送六大方式进行分发

  4. 查看原文：点击查看原文按钮，可跳转信息原文进行查看

  5. 信息复制：点击复制按钮，可复制复制或一键复制【一键复制的内容维度支持自定义设置】

  6. 标记已读：点击已读按钮，对信息进行已读标记【支持批量标记】

  7. 信息删除：点击删除，可删除信息【支持多选】、删除信息并排除来源、删除信息并排除作者【排除后将不会在该方案中看到此来源/作者发布的信息】


3.3 一键溯源

信息溯源功能仅针对微博、新闻数据，点击信息溯源功能即可快速查看该转发微博、新闻的首发信息概况、参与传播概况以及传播路径概况。

微博信息溯源

  1. 点击微博信息溯源按钮进入溯源详情，微博溯源信息包括首发信息概况、网友参与详情、传播路径

  2. 首发信息概况：展示该转发/原创微博的首发微博信息，信息包括首发微博的用户昵称、头像、关注数、粉丝数、发布时间、微博内容、转发数、评论数，点击查看原文可跳转查看原文全部信息。

  3. 网友参与详情：可快速查看参与该条微博转发的用户认证分布状态、昵称、转发内容以及转发时间；可切换用户认证状态筛选查看转发详情列表；转发详情列表记录参与转发人的昵称、转发内容以及转发时间。

  4. 传播路径：传播路径图完整的展示了微博的传播路径，相同颜色的节点代表同一转发层级，节点颜色越多代表转发层级越多，反之越少。


新闻信息溯源

  1. 点击新闻类型信息溯源按钮进入溯源详情，新闻溯源信息包括首发信息概况、网友参与详情、传播路径

  2. 首发信息概况：展示该条新闻的首发新闻信息，信息内容包括文章标题、发布时间、媒体来源、文章摘要，点击查看原文可查看该条首发新闻的原文信息。

  3. 媒体参与情况：媒体参与情况展示参与转发、传播该新闻的媒体占比及分布情况，图表展示参与该新闻的首发媒体以及媒体参与传播总数，其次展示中央级媒体、省级媒体、地级市媒体、重点媒体以及中小媒体各自所参与的媒体数量。

  4. 传播路径：传播路径图展示该新闻从首发媒体传播至其他媒体的路径详细图，可根据媒体分类切换查看参与传播媒体的来源、传播新闻的标题内容以及发布时间，媒体分类分为中央级媒体、省级媒体、地市级媒体、重点媒体以及中小媒体。


3.4 微博互动数据

  1. 互动数据：对该微博的评论数、转发数进行统计

  2. 查看互动数：点击互动数，可查看该微博的详细信息（包括但不限于头像、昵称、转发内容、发布时间等信息）、转发列表（转发者信息及转发内容）、评论列表（评论者信息及评论内容）

  3. 操作：支持对该微博信息查看原文、快速创建微博传播效果分析，对转发/评论列表数据进行导出


3.5 其他操作

  1. 数据导出：支持多选/全选信息进行导出，选择信息并创建导出任务后，可在右侧悬浮菜单-离线任务中查看历史记录并下载数据

  2. 回收站：对已删除的信息，可在右侧悬浮菜单-回收站中查看已删除的信息，7天内的数据可进行还原操作

  3. 问题反馈：问题反馈功能设置在侧边栏，用户可直接进行线上反馈，可以提交相关问题类型和模块，最多上传10张图片，可在问题列表中看到自己所提交问题及处理进度。

  4. 创建事件分析：如有全网事件分析/微博事件分析权益，点击信息列表左上侧生成事件分析，可将当前方案引用快速创建全网事件分析/微博事件分析

  5. 查看相似文章：在筛选条件中选择合并信息后，可从监测列表的相似文字条数进入二级页面【首发信息会打上首发标记】

四、图表分析

  1. 统计时间段内符合信息列表筛选条件的信息以可视化的形式呈现给用户

  2. 图表内容：含信息来源走势图、敏感占比图、信息来源占比、敏感走势、关键词云、媒体活跃度、信息行业分布图、新闻媒体网站分布图、地域分布图、微博信息发布规律图、微博类型、热门博主等13个模块

  3. 操作：支持单模块图表下载、信息明细下载、切换图表样式、放大查看、数据下载

  4. 离线任务：对时间跨度较长的图表分析，将以任务形式生成，在右侧悬浮菜单-离线任务中，可对已完成的分析任务进行管理及下载

五、定向信源设置

5.1 什么是定向监测

定向监测是基于您设置的关键词，只查看某几个网站、某几个微博账号以及某些微信公众账号的信息。


5.2 如何设置定向监测

  1. 定向网站：点击添加，选择网站，在输入框中输入该网站的域名（网站的首页地址比如www.sina.com）点击查询，或输入网站名称，在显示对应的域名中选择所需，点击添加即可【支持批量导入】

  2. 定向微博账号：点击添加，选择微博昵称，在输入框中输入微博昵称（比如上海发布），直接新增该微博账号，或模糊查询后在列表中点击添加某一微博

  3. 定向微信公众号：点击添加，选择微信公众号，在输入框中输入微信公众号（比如上海发布），直接新增该微信公众号，或模糊查询后在列表中点击添加某一公众号

  4. 定向贴吧：点击添加，选择贴吧，在输入框中输入贴吧名（比如李毅吧），直接新增该贴吧，或模糊查询后在列表中点击添加某一贴吧

  5. 定向自媒体客户端：点击添加，选择自媒体客户端，在输入框中输入客户端名称/自媒体号名称，直接新增该客户端/自媒体号，或模糊查询后在列表中点击添加某一客户端/自媒体号


5.3 定向排除

  1. 什么是排除信源：排除信源是基于系统提供的所有信源中，您可自由的排除对你无用的信源，增加信息准确性。

  2. 如何设置排除信源：定向排除的添加监测设置方式和定向监测一样，在输入框中添加需要排的域名、二级频道、微博昵称、微信公众号、贴吧名称、可以引用其他监测方案的定向排除，要打开定向排除开关才会生效。

六、预警设置

6.1 什么是预警

通过对预警词、预警内容、接收方式等条件设置，最快可分钟级下发相关舆情信息，达到及时预警、用户快速知晓舆情的效果，帮助用户从危机征兆出现到造成可感知损失的时间段内，迅速采取有效的化解和应对措施。


6.1 什么是预警

  1. 选择需要预警的方案，点击右上角预警设置，进入该方案的预警设置【也可通过系统设置—预警设置进行操作】

  2. 预警词设置：支持三组预警词，以空格隔开，预警词之间为”或“的关系，如不设将推送与方案关键词相关信息

  3. 预警内容设置：支持信息属性、来源类型、结果呈现、信息去重等14个条件进行预警信息筛选

  4. 预警接收设置：可对预警接收时间、接收时段、预警间隔、接收方式【邮件、短信、微信、钉钉、客户端、系统弹窗六种方式】、接收人、无预警通知进行设置

  5. 以上信息设置完毕后，保存即可生效


6.3 如何打开/关闭预警

  1. 进入舆情监测，选择需要开启/关闭预警的方案，点击右上角预警设置，进行开启/关闭操作

  2. 通过系统设置—预警设置，在预警管理列表中，对需要开启/关闭预警的方案进行相关操作

2.1 24小时热榜

舆情简报

一、什么是简报

1.1 简介

舆情简报是通过舆情监控系统将采集的舆情信息分类加入素材库，通过所选模块将素材快速分析生成舆情报告，关键是快速而清晰。其内容包括但不限于舆情概述、事件走势、网站统计、媒体活跃度、情感走势、处置建议等模块。


1.2 用户引导

为帮助用户快速学习简报创建流程，首次使用简报功能的用户将触发用户引导

二、简报模板

2.1 模板管理

  1. 进入简报模板后，提供政务应用（适用于政企日常报告应用的模板）；企业应用（适用于企业应用场景的模板）和自定义模板三类固定模板，可根据需求将某一模板设为默认

  2. 点击新建自定义模板，在左侧用通过鼠标拖拽的方式选择所需要的分析维度，即时预览，保存模板后将在自定义模板列表中生成一个新的模板

三、素材库

当素材库为空或需要添加更多素材时，可前往“舆情监测”、“全文搜索”、“收藏夹”选择信息添加至素材库，或前往“简报列表”，将已生成的简报进行素材提取


3.2 素材管理

  1. 复制：将本素材库的素材快捷复制到其他素材库

  2. 剪切：将本素材库的素材快捷移动到其他素材库

  3. 移动：对单条素材进行顺序调整，导出的素材将根据调整后的顺序排列，生成简报时如选择“手动排序”，将根据调整后的顺序生成简报

  4. 编辑：支持对素材标题、时间、信息属性、内容等字段按需修改，生成的简报以及数据的导出将根据编辑后的内容进行展示

  5. 删除：将选中的素材移除本素材库

  6. 导出：支持对选中的素材进行数据导出，素材导出的权益和监测列表保持一致。

  7. 筛选：支持对信息类型、时间、标题涉及词进行筛选

四、收藏夹

当收藏夹为空或需要添加更多信息时，可前往“舆情监测”、“全文搜索”、“收藏夹”选择信息添加至收藏夹。


4.2 收藏信息管理

  1. 复制：将本收藏夹的信息快捷复制到其他收藏夹

  2. 剪切：将本收藏夹的信息快捷移动到其他收藏夹

  3. 移动：对单条信息进行顺序调整，导出的信息将根据调整后的顺序排列，生成简报时如选择“手动排序”，将根据调整后的顺序生成简报

  4. 编辑：支持对信息标题、时间、信息属性、内容等字段按需修改，生成的简报以及数据的导出将根据编辑后的内容进行展示

  5. 删除：将选中的信息移除本收藏夹

  6. 导出：支持对选中的信息进行数据导出，信息导出的权益和监测列表保持一致。

  7. 筛选：支持对信息类型、时间、标题涉及词进行筛选

  2. 上传：进入简报列表，点击上传即可将本地报告文档上传至简报列表中【仅限PDF、Word、Excel格式且文件不大于2M】

  2. 查看：选择需查看的简报，点击查看按钮即可在线查看

  3. 下载：支持PDF、Word、Excel三种格式

  4. 分发：可通过邮件、短信两种渠道下发简报

  5. 提取素材：支持将某一简报使用的素材信息提取至素材库

  6. 修改：支持对简报内容进行修改，保存后将覆盖原有内容

  7. 删除：删除后将不可恢复

舆情分析

一、 全网事件分析

1.1什么是全网事件分析

全网事件分析是针对某一事件、人物、品牌、地域等进行个性化监测方案设置，从微博、微信、客户端、网站、论坛等互联网各个渠道采集并提取相关信息，按其事件概览、传播走势、媒体解析、数据透视、文本分析、舆情总结六大板块进行全方位的智能化分析，并用丰富的可视化图表呈现分析结果，分析速度大幅度提升，解读视角更为细致，视觉效果全面升级。全网事件分析包含了事件概览、传播走势、媒体解析、数据透视、文本分析、舆情总结六大板块。

1.2创建管理

  1. 点右上角的创建按钮，会跳出创建的弹框，输入任务名称（支持30个字以内）、事件涉及词（支持1000个字）、排除词（支持500个字），选择分析时间段（可回溯18个月，可分析未来7天内数据，但分析的时间跨度不能超过13个月），支持分析2000万的数据量；如果觉得麻烦可以点击引用方案，复制舆情监测中的方案；点击分析评估，会在弹框下方显示分析的信息条数和分析完成的预估时间。支持“高级设置”，即支持选择信息属性（可复选）、信息区域、来源类型、定向设置、精准设置（精准字距、精准地域、精准排除行业），使分析结果更加准确。

  2. 点击开始分析后，将不会退还所扣除的分析次数以及不支持终止分析任

  3. 如果出现提示“该事件数据量超过2亿”，即设置的方案数据量已超过限制，需要优化关键词或缩短分析时间段

  4. 当任务创建成功开始，就可以在线查看实时分析进度，也可以等任务分析完毕之后查看完整分析报告，在任务列表中点击查看按钮即可进入详情页进行查看。当该任务完成后，在任务报告里有下载按钮，点击下载按钮，选择WORD或PDF格式进行下载。

  5. 当该任务完成后，操作栏会出现更新按钮，点击更新按钮，跳出弹框，只能修改分析时间（时间间隔不能超过13个月），点击开始分析后，根据选择的分析时间段开始分析，更新是不会消耗全网时间分析的数量，最多可更新3次，但涉及词和排除词是无法更改的。



二、 微博事件分析

1.1什么是微博事件分析

根据针对某一事件、人物、品牌、地域等所配置的监测方案，从微博平台采集并提取相关信息，可分析数据为500万条,可更新分析报告次数为3次，并按其事件概览、事件传播、数据分析、用户画像和舆情总结五大维度进行自动分析，并用图表形式呈现分析结果。微博事件分析维度包含事件概览：（事件总量、热点词云、热门话题）、事件传播（信息传播走势、事件传播途径、热门信息）、数据分析（信息属性走势图、实体识别、情绪分析、用户活跃时段、微博内容分析、标签分析）、用户画像（用户认证分布、用户分布、核心传播人、意见领袖、人群特征分析、观点聚类）、舆情总结

1.2创建管理

  1. 点右上角的创建分析任务按钮，会跳出创建的弹框，输入任务名称、关键词、排除词，结果呈现，选择分析时间（可回溯历史数据18个月，分析时间跨度不超过13个月），支持引用监测方案，点击分析评估，会在弹框下方显示分析的信息条数以及报告分析完成的预估时间。

  2. 支持“高级设置”，即信息属性、定向信源、微博认证、涉及方式、、转发分类、内容属性精准设置（精准字距、精准地域、精准排除行业），使分析结果更精准。

  3. 更新报告：当该任务完成后，操作栏会出现更新按钮，点击更新按钮，跳出弹框，更新分析只支持修改排除词和分析时间。点击开始分析后，将根据新的排除词和分析时间开始分析，更新是不会消耗微博事件分析的数量。

  4. 重新分析报告：当该任务完成后，操作栏会出现分析按钮，点击分析按钮，跳出弹框，和更新不同的是可以编辑该任务的任务名、关键词、排除词、分析时间（可回溯历史数据18个月，分析时间跨度不超过13个月），需要消耗剩余分析次数。


三、 竞品分析

1.1什么是竞品分析  

竞品分析支持监测方案和自定义输入词语的对比分析；可选择时间段为18个月的数据，跨度不超过13个月。输入2~6个您关注的品牌或企业和其竞争对手，系统会从海量数据中，对双方进行量化分析，纵横对比。通过对市场走势、媒体投放情况、正负面信息、用户分析等方面对比分析，助您对行业动态了如指掌，同时也提高对市场的敏感度。竞品分析的维度包含了竞品之间的正负面传播走势对比、竞品情感分析占比、竞品正负面高频词汇显示、竞品的关键词云、竞品的信息地域分布、竞品的来源类型对比、竞品的媒体活跃度情况以及重点媒体监测。

1.2创建管理

  1. 在创建分析页面，点击添加创建，输入商品名称、关键词、排除词，再次点击添加创建输入框添加其他竞品；也可以引用舆情监测的方案，点击左侧的方案名；最多可以对比6个竞品，最后选择信息呈现的方式以及对比时间段，点击开始分析。

  2. 当竞品分析报告生成后，进入对比报告页面，点击查看，跳转至该竞品分析报告页面。

  3. 点击右侧的下载按钮，选择word或者pdf下载。点击右侧删除按钮，跳出二次确认，点击确定删除成功

四、 微博传播效果分析

1.1什么是微博传播效果分析

一款最全面的微博传播效果分析工具，具有刻画传播路径、洞察关键人物、解读用户画像、分析传播质量等功能，权威数据加便捷操作让人人都能成为分析师。微博传播分析包含了单条微博传播指数、博文概况、传播路径、转发层级、转发评论趋势图、微博传播关键用户、关键用户传播路径、引爆点、影响力排名、地域分析（转发者、评论者）、性别分析（转发者、评论者）、性别分析（转发者、评论者）、兴趣标签（转发者、评论者）、转评论内容敏感度分析、热词分析、转发提及内容、网友观点分析、转发评论表情分析、粉丝数量区间分布、发布设备分布、转发微博详情(TOP10)。

1.2创建管理

  1. 在输入框中输入要分析的微博链接，点分析按钮进行分析

  2. 当任务分析完成后可在分析记录页面中点击按钮查看当前任务的分析报告。在分析记录页面，点“删除”按钮，跳出二次确认的弹框，点确定即删除该条任务的分析记录。点击下载报告的按钮，支持word、PDF两种格式的报告下载。


五、 评论分析

1.1什么是评论分析

评论分析功能目前支持新浪网、凤凰网、网易新闻、腾讯网、南都、人民网、财经网、今日头条及一点资讯九大网站的新闻类信息的评论分析，可在某个新闻内容的详情页中获取该新闻的链接地址，输入此链接地址，即可分析该评论，以多种维度来展示此新闻事件的评论态势。评论分析的维度包含原文详情、发布概况、敏感占比、敏感关键词、词频top100、评论时间走势、评论者地域分析、转发评论者地域分析、评论者表情分析、主要观点代表者、评论观点聚类。

1.2创建管理

  1. 在创建分析页面输入需要分析的新闻地址，点分析按钮，目前只支持新浪、网易、财经网、凤凰网、南都、人民网、腾讯网、一点资讯、今日头条的新闻评论。

  2. 分析完成后在分析记录页面，点击新闻标题或者右侧查看按钮，便跳转到报告页面。点击右侧重新分析按钮，便开始重新分析该新闻的评论。

一、系统设置

  1. 预警设置：通过【系统设置】-【预警设置】，可进入所有方案的预警任务管理列表，支持开启/关闭预警，编辑/修改预警设置条件

  2. 通讯录管理：通过【系统设置】-【通讯录管理】，进入联系人信息管理列表，可查看该单位下所有联系人信息，支持新增、编辑、删除联系人

  3. 发送记录：通过【系统设置】-【发送记录】，可查看短信、邮件、微信、钉钉、客户端、系统弹窗六种渠道的发送记录，支持自定义时间、切换渠道、选择分类（短信验证码、舆情预警、手动推送、简报分发、热搜预警）筛选记录

  4. 新增抓取：支持新增需要补充抓取的网站、微博昵称、微信公众号，审核通过后3小时内会开始录入数据。

  5. 精准性问题反馈：在监测列表进入舆情信息详情时，可对该信息的敏感性判断、数据抓取、信息研判三项进行准确性反馈

  6. 偏好设置：支持对全局来源定向、默认监测条件、自定义一键复制内容维度、自定义导航栏进行个性化设置

  7. 日志：可对用户登录日志、客户端推送日志、APP用户登录日志、push中心日志进行查看

  8. 单位行为日志：统计时间段内该单位账号的预警各渠道阅读量、舆情分析使用情况、账号操作情况等行为日志数据

  9. 皮肤切换：支持冰川蓝、赤茶橘、柠檬黄、香槟金四种系统皮肤切换

二、个人中心

  1. 右上角账号昵称处，点击个人中心进入，可查看该账号方案数、舆情分析次数等权益数及已使用情况

三、常见问题

问：忘记密码如何找回？

答：在登录页点击“忘记密码”按钮，输入用户名、图片验证码、获取手机验证码，点击下一步即可重置密码


问：如何查看更新内容？

答：点击页面右上角，系统消息会显示最新更新的功能及版本号（更新后第一次登陆会自动弹出）。


问：怎么联系在线客服？

答：登录右侧悬浮模块，有客服电话和QQ客服，点击QQ客服，会自动弹出QQ聊天窗口


问：网络舆情共监测多少个网站？

答：网络舆情全网监测网站、论坛等共计超过40000个，并且还将不断更新。


问：一条信息从发布到被监测到需要多少时间？

答：网络舆情系统对百度贴吧、天涯、新浪、人民网等热点网站监测抓取时间在5分钟以内，普通网站轮询时间在半小时左右


问：微信账号都能被系统抓取监测到吗？

答：遵照国家网络安全规定，网络舆情抓取的微信号都为对外公布的公众账号


问：账号过期、权益量达到上限等问题如何处理？

答：如果在登录的时候提示账号已过期（或收到即将账号即将到期提醒邮件）、创建方案或分析任务提示权益量已达上限，您可以联系销售人员进行续费等操作
