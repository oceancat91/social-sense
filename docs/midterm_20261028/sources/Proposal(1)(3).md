## Slide 5
1. 背景与问题

难题一：空间补全
单张图片或单视角视频仅包含已知视角的信息；
生成系统必须凭空推断并补充被遮挡区域、侧面以及背面的三维几何形状与外观细节。若缺乏有效的空间约束，极易产生不同视角互相冲突的现象。（Janus 多面问题）
难题二：运动生成
单张静态图片缺乏时间信息，无法预测物体未来的动态行为；而单视角视频虽有动作参照，却缺少其他角度的运动表现；
系统需要为静态对象赋予自然流畅、符合物理规律的动态形变。

3. 从 2D 到 3D
DreamFusion：SDS 反馈如何更新三维参数？
原图：DreamFusion，Figure 1（2022）；同一生成对象的多视角渲染结果。
关键机制：冻结二维先验，更新三维表示
① NeRF 参数 θ 在随机相机 C 下渲染当前图像：x = R(θ, C)。 随机采样相机使同一组 NeRF 参数反复接受不同方向的渲染检验。
② 对渲染图加噪得到 zₜ，再由冻结的 U-Net 预测噪声 ε̂φ。 U-Net 提供图像先验反馈，不直接输出最终网格或高斯。
③ 噪声残差形成更新信号，经渲染链反传到 θ；扩散模型本身不更新。 因而监督是间接的：误差信号必须经过可微渲染链回到三维参数。

SDS 梯度示意（按论文机制简写）
∇θ L_SDS ≈ E[w(t)(ε̂φ(zₜ,y,t) − ε) · ∂x/∂θ]
残差提供反馈方向；渲染器的导数将图像反馈传回三维参数。
把公式画成闭环：反馈改的是 NeRF，不是 U-Net
三维表示 θ

渲染 x=R(θ,C)

加噪 zₜ

冻结 U-Net
噪声残差  →  梯度回传  →  更新 θ
局限：每个视角单独看起来合理，并不保证它们共享正确几何。若正面和背面都出现面部或重复部件，就会产生 Janus 多面问题。

## Slide 10

3. 从 2D 到 3D
Zero-1-to-3：让相机变化成为显式条件
原图：Zero-1-to-3，Figure 1（2023）；给定相对相机变换后生成目标视角。

相机条件的几何含义（示意图）
输入图像 I₀

相对位姿 ΔR, ΔT

目标视角 I₁
I₁ = fφ(I₀, ΔR, ΔT) ΔR：相对旋转；ΔT：相对平移
ΔR 指定相对旋转，ΔT 指定相对平移。它们把“从哪里看”变成明确输入，但模型仍然是在生成新图像，而不是直接输出一个封闭、可编辑的三维几何体。
从“像一张图”到“指定角度生成”
① Zero-1-to-3 将参考 RGB 图像与相对相机变换作为条件，生成指定角度的新视图。 相对位姿明确指定目标相机相对于输入相机的变化。
② 相机条件把观察方向变成显式输入，而不是让模型自行猜测视角。 这把视角变化从隐含因素变成显式条件，提高了生成的可控性。
③  MVDream 进一步在共同去噪过程中联合处理多个视角，并通过跨视角注意力交换信息，减少单视角先验造成的 Janus 问题。
原图：4Diffusion，Figure 2；不同扩散先验的去噪结果存在差异。
演进意义：相机条件解决“看哪里”，多视角联合先验尝试解决“不同角度是否仍是同一个对象”。但一致性仍是学习到的先验约束，而非硬性的几何保证。

4. 从 3D 到 4D
MAV3D：把时间引入三维场景表示
原图：MAV3D，Figure 1（2023）；行/列展示视角与时间变化。

从静态场景函数到动态场景函数
静态： fθ(x, y, z)     →     动态： fθ(x, y, z, t)
t₀
起始姿态

t₁
运动中

t₂
后续姿态
固定相机 C、改变 t：观察同一机位下的动作；固定 t、改变 C：观察同一姿态的不同角度。
从静态三维优化到动态场景生成
① DreamFusion 优化静态 NeRF；MAV3D 将时间 t 加入场景查询，描述同一对象在不同时间的状态。 因此，时间不是单纯的播放序号，而是参与空间查询的输入变量。
② 系统渲染多帧与随机视角，视频扩散模型为运动、外观和文本一致性提供反馈。 这避免把每一帧当成独立图像，但仍依赖视频模型学到的统计先验。
③ 视频生成器相当于一种“统计多相机监督”：不同帧和视角共同帮助优化动态场景。 这种监督并非真实多机位观测，背面与遮挡区域仍存在不确定性。
真正的 4D 不等于把图片排成视频
关键是同一个 fθ(x,y,z,t) 能解释各个时刻的空间外观。遗留问题是 T2V 先验可能带来细节/几何伪影，逐场景优化也较慢；外观、结构和动作仍难同时稳定。 评价时应同时固定相机检查运动连续性、固定时刻检查跨视角一致性。
局限：视频扩散先验不直接提供真实的背面与遮挡标注；4D 参数量和迭代优化成本也会随时间维度显著增加。

混合 SDS 的阶段示意（非论文原式）
3D-aware：建结构

不是一个先验包办所有目标
①  T2I 通常更擅长高保真外观，但缺少运动，且不保证多视角结构正确。
② 3D-aware T2I 加强多视角结构；T2V 提供运动，却可能损失外观细节。 不同先验的优化目标并不相同，直接混合可能出现监督冲突。
③  4D-fy 通过交替混合不同扩散模型的监督信号，逐步利用各自的优势，而不是让单个模型同时解决全部问题。
表格的含义：这是折中，不是全面最优
混合方法试图在外观、三维结构和运动之间重新分配监督职责。它能缓解单一先验的偏差，但多个目标之间仍可能冲突，且逐场景优化的耗时问题并未自动消失。
技术演进重点：从“选择一个更好的生成模型”转向“组织不同先验的协作方式”。

5. 联合建模
SV4D：在同一生成过程中协调视角与时间
原图：SV4D，Figure 2（ICLR 2025）；相机条件、View Attention 与 Frame Attention。

V × T：每个格子是一帧观测


















横向：同一时刻，不同视角
纵向：同一视角，不同时间
M ∈ R^(V×T×H×W×3)
View Attention
固定 t：对齐不同相机看到的同一姿态
Frame Attention
固定 v：对齐同一相机下的连续动作
两种注意力，各管一条轴
① 单目参考视频提供运动；首帧多视角图像提供初始空间参照。 首帧多视角图像补足了单目视频缺失的空间观察。
② View Attention 对齐同一时刻的不同相机；Frame Attention 对齐同一相机的连续帧。 两种注意力沿不同轴交换信息，功能互补而不能互相替代。
③ SV4D 联合生成 V×T 新视角视频，再用这些观测优化动态 NeRF。 生成观测网格后才进入动态 NeRF 优化，因此生成和资产构建仍是两个环节。
原图：4Diffusion，Figure 3（NeurIPS 2024）。
4Diffusion 将多视角视频扩散与 4D-aware SDS、anchor loss 结合；SV4D 更强调统一生成 V×T 观测网格。
另一种统一先验：4Diffusion

6. 从观测到资产
SV4D 2.0 与 L4GM：生成观测如何转成动态三维？
原图：SV4D 2.0，Figure 1（ICCV 2025）；输入视频、新视角视频与 4D 资产。
原图：L4GM，Figure 2（2024）；多视角图像、跨视角/跨时间注意力与高斯序列。
SV4D 2.0：生成视频 → 两阶段优化
L4GM：前馈预测 → 逐帧高斯
生成观测 ≠ 动态三维资产
SV4D 2.0｜优化式构建
先生成多个新视角视频，再通过两阶段优化处理视角冲突、遮挡和大幅运动。论文相较 SV4D 报告：新视角视频合成 LPIPS 改善 14%、FV4D 改善 44%；4D 优化阶段分别改善 12% 与 24%。
L4GM｜前馈式重建
利用首帧多视角补全与单目视频，网络直接预测逐帧 3D Gaussian；时间自注意力传播帧间信息，并用插值模型生成中间状态。论文报告单次前馈约 1 秒，较既有方法快约 100–1000 倍。

资产化后的观察关系
S(t) = {Gᵢ(t)};   Î(C,t) = R(S(t), C)
S(t)：时刻 t 的三维状态；R：指定相机下的渲染。
可用性检查：固定相机 C 和时刻 t，对照生成观测与三维重渲染；再固定 C 检查运动连续性、固定 t 检查跨视角几何。只看视频清晰度不够，还应分别记录生成、构建与渲染的质量和耗时。
