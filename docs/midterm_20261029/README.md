## 主要事实修订

当前成果为可运行研究原型及已有数值验证，未将语义事件对齐、GNN 传播溯源、跨话题泛化或商业可用性写成已完成。实验页同时展示方向、尖峰、误报漏报及未优于持续值的 MSE。完整文本路径与数值部署路径分开描述；经费以 7500 元申报预算为准，实际支出待凭证核账。

指定 Scholar Labs 入口当次受限，已改用原始论文来源进行重点研读并留痕；这不等于已完成 Scholar 结果筛选或系统综述。官网当次连接失败，所用截图来自仓库前端本地运行，展示内置档案数据。

## 目录与复现

```text
deliverables/   正式提交文件与讲稿
sources/        用户原件副本、文字提取、SHA256
research/       原文、重点页、笔记、检索记录
evidence/       截图、指标诊断、代码快照、最终验证与输出哈希
presentation/   ppt-master 原生模板工作区、页面计划、备注、校验
scripts/        本次文档与演示稿生成、Office 渲染、证据检查脚本
build/          中间预览和工作文件（受仓库 build/ 忽略规则影响）
```

实际调用 [ppt-master](https://github.com/hugohe3/ppt-master) 的原生模板往返流程生成 PPT。正文、流程、结构图、柱状图与表格可编辑；模板照片及页面截图为图片。母版/版式 XML 与原模板保持一致。

脚本执行顺序见 [复现说明](scripts/README.md)。后续修改应同步更新表、PPT、讲稿和证据表，完成渲染复核后再使用正式文件。`presentation/exports/` 中时间戳导出是制作记录，交付以 `deliverables/` 的可读文件名为准。

提交前只需项目组核对真实行政信息：正式项目编号、获批及实支台账、预算调剂审批（若有）、院系最新场次安排。材料没有替项目组虚构这些信息。
