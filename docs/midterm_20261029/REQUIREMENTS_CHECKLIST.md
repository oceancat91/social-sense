# 中期材料详细要求与模板阅读清单

编制：2026-10-30。依据为用户提供的 27 页知旅 PPT、13 页中期训练营 PDF、创新训练立项申请书、汇报表及专家评分表。原件副本、逐页文字提取和文件哈希保存在 `sources/`。

## 一、适用口径与优先级

1. 用户已确认按**创新训练类**制作，主讲 **6 分钟**、问答 **4 分钟**；采用已确认的 **12 页主讲 + 6 页备份**。这三项是本次制作的直接要求。
2. 知旅 PPT 是视觉与叙事模板，不是 SocialSense 的事实来源。沿用学校标识、红色斜角、白底、蓝色标题和适配的布局；旅游业务、旧姓名、日期、用户数据与性能数据全部替换。
3. 培训 PDF 明确面向**创业类项目**。其中关于讲清问题、技术、团队、证据、计划和经费的建议可借鉴；创业评分权重、融资、就业、场次时长不可自动当成本项目硬性要求。
4. 创新训练立项书与随附专家评分表用于对照目标和研究训练成效；实际完成程度以当前仓库和可检查记录为准。
5. 外校优秀案例用于改善叙事和证据组织；外校的时长、匿名要求、结题门槛不移植到本项目。详见 `research/EXCELLENT_EXAMPLES.md`。
