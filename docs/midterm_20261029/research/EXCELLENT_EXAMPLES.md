# 双创答辩案例的借鉴与改写依据

检索核对：2026-10-29/30。以下来自高校官方报道或通知。获取的是案例报道与评审要求，**不是声称已拿到获奖项目的完整 PPT 或原始实验材料**。

## 1. 广西师范大学教育学部：被评审明确肯定的项目案例

来源：[2026 年大学生创新创业训练计划项目结题答辩会报道](https://jyxb.gxnu.edu.cn/2026/0518/c8917a342338/pagem.htm)，发布于 2026-05-18，活动时间 2026-05-15。网页直读一次失败，搜索结果成功返回官方正文。

报道点名肯定《传染病威胁促使人与自然和谐共生？——基于人类中心主义视角下的多层次调查研究》的研究设计、问卷过程和成果产出；评审也强调材料与佐证整理。由此借鉴的是“问题—方法—过程—成果凭据”的顺序，而非移植其论文、实物或评价。

本项目改写：把泛泛的技术先进性改为具体代码机制；用统一时间切分、基线比较和验证 JSON 支撑实验；把尚待证明的论文、软著、溯源成果移到下一阶段计划。上述对应是本次编辑判断，不是该校对 SocialSense 的评价。

## 2. 大连理工大学软件学院：中期应呈现研究过程

来源：[2026 年大创项目中期检查通知](https://ss.dlut.edu.cn/info/1371/31012.htm)，2026-03-02。

通知强调发现问题、采用方法、实验过程、阶段成果、存在问题及后续解决路径。因此汇报表增加了负结果分析、研究训练收获及可检查的后续交付物；PPT 保留完成度、实验和风险页。其 3+2 时长与结题门槛是外校规定，不适用于本次已确认的 6+4。

## 3. 北京交通大学经济管理学院：控制叙事主线

来源：[2026 年中期答辩安排](https://sem.bjtu.edu.cn/show-342-23750.html)，2026-10-21。

参考其背景、研究问题、研究内容、进展、推进计划的组织顺序，压缩目录与章节空页。其匿名要求、3+2 时长、现场材料份数属于当地安排，没有据此删除本项目已确认的团队信息或改变时长。

## 对汇报表的具体改写原则

| 原稿容易出现的问题 | 本次改写方式 |
|---|---|
| 大量技术名称代替论证 | 先写研究问题，再写机制、证据及限制 |
| 实现与验证混为一谈 | 将接口存在、路径运行、单数据集评估、跨场景验证分别说明 |
| 只报有利指标 | 同报方向、尖峰、误报漏报和持续值 MSE 比较 |
| “创新”缺少边界 | 说明借鉴基础方法，突出面向任务的系统组合及可核查贡献 |
| 心得只写团队努力 | 写指标口径、负结果、复现、协作和研究节奏的具体认识 |
| 经费与成果语气过满 | 原预算、调剂建议、实支及正式回执分别表述 |
| 计划只有月份 | 每阶段明确交付物和验收条件，关联当前缺口 |

改写保留原项目定位、官方表格栏目和真实人员信息。没有添加虚构客户、融资、竞赛奖项、访谈样本或论文录用情况。
