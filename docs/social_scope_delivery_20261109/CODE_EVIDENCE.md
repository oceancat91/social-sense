## 后续验证工作流

1. 在公共事件、文化娱乐等不同类型中建立事件级样本；保留发布时间、采集时间、平台ID、原链接和公开引用。
2. 人工区分直接转载/引用、同源内容、仅时间相关三类关系；记录分歧和缺失，不把平台最早观测当真首发。
3. 以简单时间排序和已知引用边作基线，评价来源候选准确率、传播边精确率/召回率与错误归因。
4. 统一时序切分、训练段标准化与验证集阈值，开展分量消融、滚动和跨事件预测；保留MSE、方向与尖峰误报。
5. 实现三维等高线的时间/议题/热度编码、历史/预测分界、证据回跳和二维投影；议题轴仅为类别排布，不作语义距离。
6. 用相同任务对照二维曲线与三维视图的定位时间、判断正确率、阅读负担和目标设备帧率；未测前不宣称视觉方案必然更优。

社区或社会价值围绕来源核验、议题理解和有依据的回应；商业服务作为后续应用探索，当前验收以研究证据为主。
