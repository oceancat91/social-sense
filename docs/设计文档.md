# Social Sense 系统设计文档

## 1. 系统架构设计

### 1.1 整体架构

系统采用前后端分离的 B/S 架构，分为以下几个层次：

```
┌────────────────────────────────────────────┐
│                 用户层                      │
│         浏览器 / 移动端                      │
├────────────────────────────────────────────┤
│                 前端层                      │
│     React/Vue + ECharts 可视化              │
├────────────────────────────────────────────┤
│                 接口层                      │
│        RESTful API / WebSocket             │
├────────────────────────────────────────────┤
│                 业务层                      │
│   用户管理 | 数据采集 | 分析引擎 | 预警服务   │
├────────────────────────────────────────────┤
│                 数据层                      │
│     MySQL | Redis | MongoDB (可选)          │
└────────────────────────────────────────────┘
```

### 1.2 模块划分

- **用户模块**：注册、登录、权限管理
- **采集模块**：爬虫管理、数据清洗、数据存储
- **分析模块**：NLP 处理、情感分析、热点发现
- **展示模块**：数据看板、图表渲染、报告导出
- **预警模块**：阈值监控、消息推送

## 2. 数据库设计

### 2.1 核心数据表

#### 用户表 (users)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT (PK) | 主键 |
| username | VARCHAR(50) | 用户名 |
| email | VARCHAR(100) | 邮箱 |
| password_hash | VARCHAR(255) | 密码哈希 |
| role | VARCHAR(20) | 角色 |
| created_at | DATETIME | 创建时间 |

#### 监控任务表 (monitor_tasks)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT (PK) | 主键 |
| user_id | INT (FK) | 所属用户 |
| keywords | TEXT | 监控关键词 |
| platform | VARCHAR(50) | 目标平台 |
| status | VARCHAR(20) | 任务状态 |
| created_at | DATETIME | 创建时间 |

#### 舆情数据表 (sentiment_data)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT (PK) | 主键 |
| task_id | INT (FK) | 关联任务 |
| content | TEXT | 内容文本 |
| source | VARCHAR(100) | 来源 |
| sentiment | VARCHAR(20) | 情感标签 |
| score | FLOAT | 情感得分 |
| published_at | DATETIME | 发布时间 |
| collected_at | DATETIME | 采集时间 |
