# Social Sense 公网部署指南

## 方案概览

本指南使用两台免费云平台完成公网部署：

| 部分 | 平台 | 免费额度 |
|------|------|----------|
| 前端（React） | Vercel | 100GB 带宽/月，自动 HTTPS |
| 后端（Flask） | Render | 750 小时/月，2GB 持久化磁盘 |
| 数据库 | Render 磁盘 | SQLite 保存在 Render 持久化磁盘 |

部署完成后你将得到一个公网可访问的完整系统。

---

## 前置准备

1. 一个 [GitHub](https://github.com) 账号（已用）
2. 一个 [Vercel](https://vercel.com) 账号（用 GitHub 登录）
3. 一个 [Render](https://render.com) 账号（用 GitHub 登录）

---

## 第一步：部署后端到 Render

### 1.1 登录 Render

访问 [dashboard.render.com](https://dashboard.render.com)，用 GitHub 账号登录。

### 1.2 创建 Web Service

1. 点击 **New +** → **Web Service**
2. 授权 Render 访问你的 GitHub 仓库，选择 `oceancat91/social-sense`
3. Render 会自动检测到仓库根目录的 `render.yaml`，点击 **Apply**

> **手动配置**（如果自动检测失败）：
> - Name: `social-sense-api`
> - Region: `Singapore`
> - Root Directory: `backend`
> - Build Command: `pip install -r requirements.txt`
> - Start Command: `gunicorn run:app -w 2 --timeout 120 -b 0.0.0.0:$PORT`

### 1.3 挂载持久化磁盘

在服务的 **Disks** 标签页，添加磁盘：
- Name: `data`
- Mount Path: `/var/data`
- Size: `2 GB`

### 1.4 设置环境变量

在 **Environment** 标签页添加：

| Key | Value |
|-----|-------|
| `DB_DRIVER` | `sqlite` |
| `SQLITE_PATH` | `/var/data/social_sense.db` |
| `APP_SECRET_KEY` | 点击 Generate（自动生成随机密钥） |
| `ADMIN_EMAIL` | `admin@social-sense.com` |
| `ADMIN_PASSWORD` | 设置一个密码 |
| `TRANSFORMERS_CACHE` | `/var/data/model_cache` |
| `HF_HUB_DISABLE_XET` | `1` |
| `SENTIMENT_MODEL_NAME` | `lxyuan/distilbert-base-multilingual-cased-sentiments-student` |

### 1.5 等待部署完成

Render 会自动构建并启动。首次构建约 3-5 分钟。部署成功后，访问 `https://social-sense-api.onrender.com/health` 看到 `{"status":"ok","db":true}` 即表示成功。

> **注意**：Render 免费实例 15 分钟无请求会自动休眠，下次请求需等待约 30 秒唤醒。这是免费套餐的正常行为。

---

## 第二步：部署前端到 Vercel

### 2.1 获取后端地址

记下 Render 部署后给你的地址，例如：`https://social-sense-api.onrender.com`

### 2.2 登录 Vercel

访问 [vercel.com](https://vercel.com)，用 GitHub 账号登录。

### 2.3 导入项目

1. 点击 **Add New** → **Project**
2. 选择 `oceancat91/social-sense`
3. 配置以下选项：

| 配置项 | 值 |
|--------|-----|
| Root Directory | `frontend` |
| Framework Preset | Vite（自动检测） |

4. 展开 **Environment Variables**，添加：

| Key | Value |
|-----|-------|
| `VITE_API_BASE_URL` | `https://social-sense-api.onrender.com/api/v1` |

> 这里替换为你的 Render 后端实际地址

5. 点击 **Deploy**

### 2.4 等待部署完成

部署约需 1-2 分钟。成功后 Vercel 会给你一个地址，例如：`https://social-sense.vercel.app`

你可以在 Vercel 的 **Domains** 设置中绑定自己的域名。

## 第三步：初始化演示数据

部署完成后，后端数据库是空的。你需要在本地执行一次种子数据脚本，指向远程后端：

在项目根目录的终端中执行：

```bash
.\.venv\Scripts\python.exe -c "
import requests, time
# 替换为你的 Render 后端地址
BACKEND = 'https://social-sense-api.onrender.com/api/v1'

r = requests.post(f'{BACKEND}/auth/login',
    json={'email':'admin@social-sense.com','password':'admin123'})
token = r.json()['data']['token']
headers = {'Authorization': f'Bearer {token}'}

r2 = requests.post(f'{BACKEND}/tasks',
    json={'keywords':['校园食品安全'],'platform':'all','days':14},
    headers=headers)
print('任务创建:', r2.json().get('message'))

print('等待采集中（约 1-2 分钟）...')
time.sleep(90)

r3 = requests.get(f'{BACKEND}/analysis/overview', headers=headers)
print('数据总量:', r3.json()['data']['total'])
print('平台数:', r3.json()['data']['platform_count'])
"
```

> **提示**：Render 免费套餐首次请求需等待 30 秒冷启动（服务休眠唤醒），加上模拟数据生成，整个过程约需 2-3 分钟。完成后刷新前端页面即可看到跨平台舆情数据。

## 常见问题

### 前端页面空白/API 报错

检查 Vercel 的 `VITE_API_BASE_URL` 环境变量是否设置正确，注意结尾不要带斜杠。

### 后端 502 错误

Render 免费实例可能已休眠，等待 30 秒后刷新即可。

### 想使用预训练情感模型

Render 免费套餐内存有限（512MB），预训练模型可能需要更多资源。如需启用：
1. 升级到 Render 付费计划（$7/月起，存储扩容到 50GB）
2. 或购买一台 2核4G 云服务器用 Docker Compose 部署

当前 Render 免费环境使用词典情感分析，准确率约 62%。

### 想用自己的域名

Vercel 和 Render 都支持绑定自定义域名，在各自平台的 **Domains / Settings** 中配置即可。Vercel 会自动签发 SSL 证书。
