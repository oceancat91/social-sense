# Social Sense 部署文档

## 1. 环境准备

### 1.1 服务器要求

- **操作系统**: Ubuntu 20.04+ / CentOS 7+
- **CPU**: 2核+
- **内存**: 4GB+
- **硬盘**: 50GB+

### 1.2 软件依赖

- Python 3.9+
- Node.js 16+
- MySQL 8.0+
- Redis 6.0+
- Nginx
- Docker & Docker Compose（推荐）

## 2. Docker 部署（推荐）

### 2.1 一键部署

```bash
# 克隆项目
git clone https://github.com/oceancat91/social-sense.git
cd social-sense

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件

# 启动服务
docker-compose up -d
```

### 2.2 查看服务状态

```bash
docker-compose ps
docker-compose logs -f
```

## 3. 手动部署

### 3.1 数据库配置

```bash
# 创建数据库
mysql -u root -p
CREATE DATABASE social_sense CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3.2 后端部署

```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python run.py
```

### 3.3 前端部署

```bash
cd frontend
npm install
npm run build
```

### 3.4 Nginx 配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        root /path/to/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    location /api {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 4. 常见问题

### Q: 数据库连接失败？
A: 检查 `.env` 中数据库配置是否正确，确认 MySQL 服务已启动。

### Q: 前端页面空白？
A: 检查 Nginx 配置中的静态文件路径是否正确。
