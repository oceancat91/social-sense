# Social Sense 腾讯云部署指南

## 方案概览

| 部分 | 方案 | 说明 |
|------|------|------|
| 服务器 | 腾讯云轻量应用服务器 | 2核2G / Ubuntu 22.04 |
| 前端 | Nginx（容器内） | 端口 80，反向代理到后端 |
| 后端 | Flask + Gunicorn（容器内） | 内置 MySQL 健康等待 |
| 多 Agent 引擎 | agent/ + multiagent/（只读挂载进后端容器） | 跨平台对齐·融合·茧房指数 |
| 数据库 | MySQL 8.0（容器内） | utf8mb4 编码，数据持久化 |
| 缓存 | Redis 7（容器内） | 会话缓存 |
| 部署方式 | Docker Compose | 一条命令全部拉起 |

---

## 前置准备

1. 腾讯云账号，购买**轻量应用服务器**（学生价约 10 元/月）
2. 配置规格：2核2G，系统镜像选 **Ubuntu 22.04**
3. 购买后在控制台 → **防火墙** 中开放 `80` 端口（HTTP）

## 部署步骤

### 第一步：SSH 登录服务器

在轻量应用服务器控制台点击 **"登录"**（网页终端即可），或者本地用 SSH：

```bash
ssh root@你的服务器公网IP
```

### 第二步：运行一键部署脚本

```bash
bash <(curl -sSL https://raw.githubusercontent.com/oceancat91/social-sense/main/deploy/tencent-cloud/setup.sh)
```

脚本会自动完成：
1. 安装 Docker + Docker Compose
2. 克隆项目代码
3. 生成强随机密钥和数据库密码
4. 构建 Docker 镜像并启动所有服务
5. 等待数据库就绪后灌入演示数据

整个过程约 5-8 分钟。

### 第三步：访问

部署完成后脚本会输出：

```
访问地址:  http://你的服务器IP
登录邮箱:  admin@social-sense.com
登录密码:  admin123
```

## 手动部署（分步执行）

如果不想用一键脚本：

```bash
# 1. 安装 Docker
curl -fsSL https://get.docker.com | bash

# 2. 克隆项目
git clone https://github.com/oceancat91/social-sense.git
cd social-sense

# 3. 创建配置
cp deploy/tencent-cloud/.env.production .env
# 编辑 .env，修改 DB_PASSWORD 和 APP_SECRET_KEY
# 生成密钥：python3 -c "import secrets; print(secrets.token_hex(32))"
# 可选：配置 DEEPSEEK_API_KEY 以启用多 Agent 引擎的 LLM 结论生成与主控归纳
# （未配置时自动降级为确定性规则，仍可跑通跨平台融合）

# 4. 启动所有服务
docker compose up -d --build

# 5. 灌入演示数据
docker compose exec backend python -c "
from app import create_app, db
from app.models.user import User
from app.models.task import MonitorTask
from app.services.pipeline_service import PipelineService
app = create_app()
with app.app_context():
    user = User.query.filter_by(username='admin').first()
    task = MonitorTask(user_id=user.id, keywords='校园食品安全', platform='all', status='collecting')
    db.session.add(task); db.session.commit()
    PipelineService.run_task_pipeline(app, task.id, days=14, limit=600)
    db.session.expire_all()
    print(f'数据量:', db.session.get(MonitorTask, task.id).data_count)
"
```

## 绑定域名 + HTTPS（可选）

### 1. 购买域名并解析

在腾讯云 **DNS 解析** 中添加 A 记录，指向服务器 IP。

### 2. 使用 Nginx Proxy Manager

```bash
# 新建一个目录
mkdir -p ~/nginx-proxy && cd ~/nginx-proxy

# 创建 docker-compose.yml
cat > docker-compose.yml <<'EOF'
version: '3'
services:
  nginx-proxy:
    image: jc21/nginx-proxy-manager:latest
    ports:
      - "80:80"
      - "443:443"
      - "81:81"
    volumes:
      - ./data:/data
      - ./letsencrypt:/etc/letsencrypt
    restart: unless-stopped
EOF

docker compose up -d
```

访问 `http://服务器IP:81`：
- 默认邮箱: `admin@example.com`
- 默认密码: `changeme`

添加 Proxy Host，反代到 `social-sense-frontend:80`，一键申请 Let's Encrypt SSL 证书。

### 3. 修改原服务的端口

编辑 `docker-compose.yml`，把 frontend 的 `80:80` 改为 `8080:80`，避免与 Nginx Proxy Manager 冲突。

## 架构总览

```
用户浏览器
    │
    ▼
┌──────────────────────┐
│  腾讯云防火墙 (80)     │
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│  frontend (Nginx:80) │  ← 静态页面 + API 反向代理
└──────────┬───────────┘
           ▼ /api/*
┌──────────────────────┐
│  backend (Flask:5000)│  ← 业务逻辑 + NLP 分析 + 多 Agent 引擎
│   ├─ agent/          │     单平台 Skill1–6（只读挂载）
│   └─ multiagent/     │     跨平台对齐·融合·茧房指数
└──────┬───────┬───────┘
       ▼       ▼
┌──────────┐ ┌──────┐
│  MySQL   │ │Redis │  ← 数据持久化
│  :3306   │ │:6379 │
└──────────┘ └──────┘
```

所有服务跑在同一台服务器上，通过 Docker 内部网络通信，MySQL 和 Redis 端口不暴露到公网。

## 多 Agent 引擎配置与验证

### 关键环境变量

| 变量 | 必填 | 说明 |
|------|------|------|
| `DEEPSEEK_API_KEY` | 否 | 启用 Skill5/6 结论生成与主控归纳的 LLM；未配置自动降级为确定性规则 |
| `DEEPSEEK_MODEL` | 否 | 默认 `deepseek-chat` |
| `AGENT_ROOT` | 否 | agent 代码目录，容器内默认 `/app/agent` |
| `MULTIAGENT_ROOT` | 否 | multiagent 代码目录，容器内默认 `/app/multiagent` |
| `AGENT_OUTPUT_DIR` | 否 | 引擎中间产物目录（知识库 / 隐状态），默认 `/app/agent_outputs`（已挂卷持久化） |

### 数据源说明

云端多 Agent 引擎**不依赖真实 B 站爬虫 / cookie**，而是把后端 `SentimentData`（模拟数据源 + 情感分析）转成标准 `D_platform` 契约后，跑单平台 Skill2–6 与跨平台融合。因此：

- 无需在服务器上配置 B 站鉴权；
- 未来接入真实采集器时，只需替换 `agent_engine.py` 中的数据源转换层。

### 部署后验证

```bash
# 1. 登录获取 token
curl -s http://服务器IP/api/v1/auth/login -H 'Content-Type: application/json' \
  -d '{"email":"admin@social-sense.com","password":"admin123"}'

# 2. 探测引擎可用性（返回 available: true 即部署成功）
curl -s http://服务器IP/api/v1/agent/status -H 'Authorization: Bearer <token>'

# 3. 创建跨平台分析任务（需已有采集任务数据，或先用 seed 灌数据）
curl -s http://服务器IP/api/v1/agent/analyze -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: application/json' \
  -d '{"keyword":"校园食品安全","platforms":["bilibili","weibo"]}'

# 4. 查看报告（status=success 后，result.cross_platform 含茧房指数）
curl -s http://服务器IP/api/v1/agent/reports -H 'Authorization: Bearer <token>'
curl -s http://服务器IP/api/v1/agent/reports/1 -H 'Authorization: Bearer <token>'
```

docker compose logs -f backend

ls -d agent multiagent
