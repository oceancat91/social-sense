# 模型介绍

## 一句话

一个把历史数值序列**分解成四个可加分量**、并用**对齐文本按分量增强**的时序模型，用于**短期热度预测 + 事件归因**。

$$
\hat{y}_{L+1:L+P}
=
\hat{T}
+
\hat{S}
+
\hat{C}
+
\hat{R}
$$

默认历史长度 \(L=28\)、预测长度 \(P=6\)、单变量。架构零改动即可从 Climate/Traffic 换到社交热度数据。

## 四个分量

| 分量 | 负责什么 | 关键设计 |
|---|---|---|
| \(\hat{T}\) 趋势 | 低频振幅外推 | **尺度等变**：`s·MLP(ΔT/s)` 与普通 `MLP(ΔT)` 用「尺度 OOD 门」混合，能在训练没见过的振幅上外推 |
| \(\hat{S}\) 季节 | 周期结构（星期等） | 相位由日历决定；文本只调制幅度，不改周期位置 |
| \(\hat{C}\) 冲击 | 外生事件触发的响应 | **只有外生事件才激活**，无事件时 \(\hat{C}\equiv 0\)；不从数值里猜跳变时刻 |
| \(\hat{R}\) 残差 | 去趋势/季节/冲击后的谱残差 | 多频带谱头 + 可选文本 FiLM |

## 分解

历史窗口先做两级分解：

$$
r_1,\ T = \mathrm{EMA}(x),\qquad
r_2,\ S = \mathrm{Fourier}(r_1;t),\qquad
R = r_2 - C_{\mathrm{hist}}.
$$

\(C_{\mathrm{hist}}\) 是训练集上用 PELT 标出的历史冲击，只用于定义残差和构造响应模板。

## 文本接入（DS-SAA）

冻结的 GPT-2（第 6/9/12 层池化）把两类文本映到同一语义维：

- **内生**：当前窗口数值摘要模板 + 分量指令；
- **外生**：与时间戳对齐的事实文档，解析成事件元组。

每个分量用自己的数值查询对内生/外生做交叉注意力，再残差融回时间特征。外生注意力带**语义路由**（文档先分到分量，低路由概率不参与）。文本用法按分量不同：

| 分量 | 文本角色 |
|---|---|
| \(T\) | 仅内生；训练尺度内的小残差，尺度 OOD 时乘 \((1-w)\) 关闭 |
| \(S\) | 内生+外生，只调幅度 |
| \(R\) | 内生+外生，调制谱残差 |
| \(C\) | 事件元组驱动，走事件响应头 |

## 训练（三阶段）

| 阶段 | 更新谁 | 目标 |
|---|---|---|
| 1 | EMA、两条趋势头、季节、残差 | 纯数值骨干；随后拟合尺度门参数 |
| 库 | 响应模板与触发头 | PELT 片段拟合 + 点过程 |
| 2 | 文本融合与文本头（数值骨干冻结） | 预测 MSE + \(L_{\mathrm{orth}}\) + \(L_{\mathrm{route}}\) + 点过程 |
| 3 | 端到端微调（文本编码器除外） | 同阶段 2，更小学习率 |

验证集在 \(\{C 开/关\}\times\{丢掉 T,S,R 文本子集\}\) 上选最终通路，误差接近时保留更少文本通路。

## 本项目任务适配

- **数据**：社交帖文按天聚合 → `OT`（日发帖量）+ `fact`（当日 top-k 高赞文本）+ `date`。
- **目标变换**：原始 `OT` 是幂律长尾（max 25166 vs median 95，skew 11.8），直接 MSE 会爆。目标改用 `log1p(OT)`，动态范围压到 [2.5, 10.1]，skew 降到 1.5。
- **主叙事**：**异常检测 + 事件归因**。尖峰不是要拟合的噪声，而是要解释的信号。

## 输入 / 输出

输入（每个预测时刻）：

| 字段 | 含义 |
|---|---|
| 历史窗口 \(x_{1:28}\) | 最近 28 天热度（log 空间） |
| `date` | 这 28 天日期 |
| `fact` | 对齐文本（`YYYY-MM-DD: 正文; ...`） |

输出：

| 输出 | 含义 |
|---|---|
| \(\hat y_{1:6}\) | 未来 6 天热度预测（log 空间，可 `expm1` 还原） |
| \(\hat T,\hat S,\hat C,\hat R\) | 可解释分量 |
| `fire` / \(\hat C\) | 是否触发外生冲击、冲击形态 |
| 路由事件文本 | 归因素材 |

## 预测口径（重要）

社交热度序列高度自相关（lag=1 ≈ 0.90），「昨天多少今天还多少」的 persist 基线在点对点 MSE 下
白捡了 0.9 的相关性，模型拼 MSE 永远吃亏。因此本项目**不拼点对点 MSE**，改用两个更有价值的口径
（persist 在这两个口径下恒为 0）：

| 口径 | 定义 | 结果（模型 vs persist） |
|---|---|---|
| **方向命中率** | 未来 6 天均值涨/跌判断正确率 | **65.1%** vs 12.8% |
| **尖峰预警** | 「预测会明显上涨」召回真实尖峰的比例 | **74.2%** vs 0% |

`test_event_response_e2e.py --direction` 会同时输出这两组指标（还有尖峰 AUC、幅度校准诊断）。
加长窗口 `L=8→28`、季节周期 `12→7` 后方向与尖峰 AUC 均上升，已设为默认。

## 中间产物接 AI

结构化中间结果（预测曲线、分量、触发文本、异常 z 分数、平台分布）可直接喂给本地大模型（Ollama）生成自然语言报告，见 `scripts/llm_reporter.py`。数值归模型，话术归 AI。
