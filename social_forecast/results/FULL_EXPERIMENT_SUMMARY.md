## B. 模型训练（辅助，架构零改动）

### 冲击库修复（关键）

```text
上次：PELT empty → snippets=0 → fire≡0
本次：PELT empty → anomaly BPs=11 (train-only) → snippets=11
```

说明：**异常日回填后，C + 文本路由通路已能工作**（不再是空库）。

### Test MSE（log1p 空间，L=28）

| 方法 | MSE |
|---|---|
| persist | **1.525** |
| stage1 TS | 1.856 |
| stage3 +text（最终门） | 1.887 |

最终门：`C=off, drop=['T','S','R']` —— 验证集按 MSE 仍认为文本不帮预测。  
相对 persist 仍差约 +22%（L=8 时为 +34%，加长窗口后差距缩小）。**点对点 MSE 不是主卖点。**

### 方向命中率 + 尖峰预警（换口径，不拼 MSE）

这才是预测线真正的价值。persist 恒输出平线 → 方向恒 0、尖峰永不预警（两个指标都 0%）。

| 指标 | 模型 | persist |
|---|---|---|
| **方向命中率**（涨/跌，排除平） | **65.1%** | 12.8%（≈0） |
| **尖峰 recall**（预测"会涨"即预警） | **74.2%** | 0% |
| 尖峰 precision | 29.3% | 0% |
| 尖峰 F1 | 0.421 | 0% |
| 尖峰 AUC（阈值无关） | 0.613 | 0.500 |

关键事实链：

1. **尖峰预警 ≈ 方向预测**：98.5% 的尖峰窗口，未来 6 天均值也在涨——"预警尖峰"和"预测上涨"本质同一件事。
2. **recall 74% 就是方向命中率的自然结果**：模型方向判断对的窗口，尖峰就被顺带预警了。
3. **precision 29% 是数据稀疏性**（尖峰只占 25%）决定的，oracle 完美方向也只有 44.6%。
4. 幅度被 MSE 压扁 3–5 倍（AUC 仅 0.613），这是回归训练的固有偏差，不影响方向/预警口径。

### L=8 → L=28 的收益

| 指标 | L=8 | L=28+period7 |
|---|---|---|
| stage1 TS MSE | 1.998 | **1.856** |
| 方向命中率 | 64.7% | **65.1%** |
| 尖峰 AUC | 0.573 | **0.613** |
| 尖峰 recall@任意涨 | 65.2% | **74.2%** |

→ **更长窗口让趋势头看到更多历史，全面更优；L=28 已设为默认。**

## C. 结论

1. **全量实验跑通且未死机。**
2. **交付重心**：异常检测（28 事件）+ 文本归因（`events.jsonl` / 报告）。
3. **预测线的正确叙事**：不拼点对点 MSE（数据高度自相关，persist 白捡 0.9 相关性），而是
   **方向命中率 65.1% + 尖峰 recall 74.2%**，两者均碾压 persist 的 0%。
4. **模型侧进展**：异常日 → 冲击库后 `fire` 可达 11.5%，通路打通；文本在全局 MSE 上仍被门控关闭
   （符合「预测弱、归因强」），但预测价值由方向/尖峰口径承载。
5. **下一步可选**：用异常窗口专项评测 C（不按全局 MSE 关门）；接 Ollama/自有 AI 把 `events.jsonl` 写成自然语言报告。
